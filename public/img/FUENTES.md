# Procedencia de los recursos visuales (prototipo)

Todo lo que se usa en la interfaz y no es código propio. Sirve para revisar el copyright antes de publicar.
Fechas de descarga: 12 y 13/10/2026. Las licencias son las que declara la página de origen (Wikimedia Commons, salvo que se indique otra cosa); «dominio público» = la propia ficha de Commons lo marca como tal.

Los grabados, adornos y emblemas están convertidos a **máscara de tinta** (WebP con alfa: tinta opaca, papel transparente) para pintarlos con `mask-image` y el color del tema. Los arcanos van a color tal cual.

## Iconos de interfaz

Lucide (https://lucide.dev), licencia ISC, descargados con `php artisan flux:icon` desde https://github.com/lucide-icons/lucide a `resources/views/flux/icon/`. Las copias con nombre de heroicon (`x-mark`, `chevron-up-down`, `eye-slash`, `exclamation-triangle`, `bars-2`, `cog`, `arrow-right-start-on-rectangle`, `home`, `magnifying-glass`, `computer-desktop`) son el mismo icono Lucide, para que los componentes internos de Flux usen una sola familia. Cada archivo lleva su `{{-- Credit: Lucide --}}`.
